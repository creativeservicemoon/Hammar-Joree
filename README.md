# Hammar Joree

A mobile-first React + Vite starter website and PWA for the Hammar Joree Community & Life Partner Platform.

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The static production files are generated in `dist/`.

## Cloudflare Pages settings
- Framework preset: Vite
- Build command: `npm run build`
- Build output directory: `dist`
- Production branch: `main`

This starter is a public landing page only. Registration, authentication, member profiles, matching, private chat, payments and admin moderation are not implemented yet. Add secure backend functionality before accepting real member data.
